# social

Openbare kopieën van de Instagram-content, alleen omdat de Instagram Graph API
media niet accepteert als upload: hij haalt het bestand zelf op van een publieke
HTTPS-URL, zonder querystring. Vandaar dat ze hier staan en niet alleen in
`content/instagram/` (dat is gitignored, want dat is renderuitvoer).

Bestanden zijn opnieuw te maken met `node render-content.js`.

Na de laatste geplande post (16 augustus) kan deze map weg.
